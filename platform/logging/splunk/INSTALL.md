# Splunk Integration Guide

This folder contains everything you need to install Splunk Enterprise on a VM
across AWS EC2, Azure VM, GCP Compute Engine, and OCI VM, as well as forward logs
from Kubernetes to Splunk using Splunk Connect for Kubernetes (SCK).

Contents:
- splunk-hec-config.yaml
- splunk-connect-values.yaml
- VM install scripts for AWS, Azure, GCP, and OCI
